# 糖糖
README | [English](README.md) | 中文（简体）

![糖糖](data/icons/hicolor/scalable/apps/com.github.mimiaomc.candytracker.svg)

**糖糖**是一个用来记录用药（例如跨性别 HRT 方案）的应用程序，基于 GTK4 开发。

## 功能特点
- 记录每日用药信息
- 图表展示用药历史及趋势
- 简洁的 GTK4 界面
