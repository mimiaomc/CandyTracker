# CandyTracker
README | English | [中文（简体）](README.zh_CN.md)

![CandyTracker](data/icons/hicolor/scalable/apps/com.github.mimiaomc.candytracker.svg)

**CandyTracker** is an application for recording medication usage (for example, tracking transgender HRT schedules).
It is built with GTK4.

## Features
- Record daily medication information
- Display medication history and trends with charts
- Simple GTK4 interface
